# Tamil Launcher

Jetpack Compose Android launcher with Tamil UI (default), app drawer, dock, folders, widgets,
icon packs, themes, app hiding/locking, focus mode, gestures, notification badges and backup/restore.

## Build
- Android Studio: open this folder, sync, then Build > Build APK(s).
- GitHub: push to `main`; the **Build APK** workflow uploads the debug APK as an artifact (Actions tab).
